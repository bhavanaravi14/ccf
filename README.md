# Customer Segmentation Using RFM Analysis

## 1. Project Overview
This project focuses on customer segmentation using RFM (Recency, Frequency, Monetary) analysis.

RFM analysis is a customer analytics technique used to understand customer purchasing behavior and identify valuable customer groups.

## 2. Project Objectives
- Analyze customer purchasing patterns.
- Calculate Recency, Frequency, and Monetary values.
- Segment customers based on purchasing behavior.
- Identify valuable and inactive customer groups.
- Generate insights to support business decisions.

## 3. Dataset Description
The project uses transactional sales data.

Common attributes include:
- Customer ID
- Invoice Number
- Invoice Date
- Quantity
- Unit Price
- Transaction Amount

## 4. Tools and Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 5. Implementation Steps
1. Imported the necessary libraries.
2. Loaded and explored the dataset.
3. Cleaned missing and duplicate records where applicable.
4. Prepared transaction dates and customer information.
5. Calculated Recency, Frequency, and Monetary values.
6. Created RFM scores.
7. Segmented customers based on their RFM scores.
8. Visualized customer segments and analyzed the results.

## 6. Key Outcomes
- Identified different customer groups.
- Analyzed customer purchasing frequency and spending behavior.
- Identified potentially valuable and inactive customers.
- Generated insights that can support customer retention strategies.

## 7. How to Run the Project
1. Clone this repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells to reproduce the analysis.

## 8. Conclusion
RFM analysis provides useful insights into customer behavior and helps businesses develop better customer engagement and retention strategies.
